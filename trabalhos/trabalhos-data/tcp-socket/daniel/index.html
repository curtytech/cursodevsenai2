Conceito fundamental · 02

O que é um Socket?

Um socket é um ponto de comunicação usado por programas para enviar e receber dados através de uma rede.

Endereço IP

Identifica o dispositivo na rede, por exemplo 192.168.1.10.

Porta

Ajuda a identificar o serviço, por exemplo 8080.

Um socket TCP é associado a um endereço IP e a uma porta. Uma conexão é identificada pelos endereços e portas das duas extremidades.
Protocolo · 03

Como funciona o TCP?

TCP significa Transmission Control Protocol. Ele oferece um fluxo de bytes confiável, ordenado e orientado à conexão.

Confiabilidade

Usa confirmações e retransmissões para lidar com perdas de segmentos.

Ordem

Entrega os bytes à aplicação na ordem correta.

Controle de fluxo

Evita sobrecarregar o receptor.

Controle de congestionamento

Ajusta o envio conforme as condições da rede.

Comparação · 04

TCP × UDP

TCP

Orientado à conexão, entrega ordenada e retransmissão de dados perdidos.

Exemplos: HTTPS, SSH, transferência de arquivos.

UDP

Baseado em datagramas, sem garantia de entrega ou ordenação pelo próprio protocolo.

Exemplos: DNS tradicional, chamadas em tempo real e jogos.

TCP não significa sempre mais rápido: a escolha depende da necessidade da aplicação.

O servidor aguarda conexões em uma porta. O cliente inicia a conexão para o endereço e a porta do servidor.

Depois de conectados, ambos podem enviar e receber dados.

Transmissão · 07

Como os dados circulam?

sendall()
→
TCP / rede
→
recv()

O TCP transporta um fluxo contínuo de bytes, e não mensagens separadas automaticamente.

Por isso, uma chamada a recv() pode receber somente parte do que foi enviado ou dados de vários envios. A aplicação deve definir como separar mensagens, por exemplo usando tamanho ou delimitadores.

Endereçamento · 08

IP e portas

127.0.0.1

Endereço de loopback: permite testar cliente e servidor no mesmo computador.

Porta 5000

Exemplo de porta de aplicação para nossos testes locais.

Em um servidor público, regras de firewall, roteamento e permissões também podem afetar a conexão.

O par 127.0.0.1:5000 será utilizado no exemplo a seguir.
Prática · 09

Servidor TCP em Python

import socket

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as servidor:
    servidor.bind(("127.0.0.1", 5000))
    servidor.listen()
    print("Aguardando cliente...")
    conexao, endereco = servidor.accept()
    with conexao:
        dados = conexao.recv(1024)
        if dados:
            print("Recebido:", dados.decode("utf-8"))
            conexao.sendall(b"Mensagem recebida!")

Salve como servidor.py e execute primeiro.

Prática · 10

Cliente TCP em Python

import socket

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as cliente:
    cliente.connect(("127.0.0.1", 5000))
    cliente.sendall("Ola, servidor!".encode("utf-8"))
    resposta = cliente.recv(1024)
    print(resposta.decode("utf-8"))

Em outro terminal, execute python cliente.py. O cliente envia uma mensagem e o servidor responde.

Exemplo didático de troca curta. Em sistemas reais, trate erros, timeouts e mensagens maiores.
Aplicações · 11

Onde TCP Socket é usado?

Web

HTTP/1.1 e HTTP/2 normalmente utilizam TCP.

Acesso remoto

SSH usa TCP para sessões remotas.

Banco de dados

Muitos bancos aceitam conexões de clientes por TCP.

Aplicações próprias

Chats, serviços internos e sistemas cliente-servidor.

Boas práticas · 12

Segurança e conclusão

Cuidados essenciais

Use TLS quando houver dados sensíveis; valide entradas; limite o tamanho de mensagens; configure timeouts; autentique usuários quando necessário.

O que aprendemos?

Socket é a interface de comunicação; TCP fornece conexão e fluxo confiável de bytes; IP e porta identificam os destinos.
