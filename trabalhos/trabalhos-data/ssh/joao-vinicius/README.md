# SSH na prática

Projeto didático em HTML, CSS e JavaScript puro. Não utiliza Node.js.

## Como abrir
Extraia a pasta e abra `index.html` no navegador. No VS Code, também pode usar o Live Server.

## Recursos
- Apresentação em 12 etapas, com navegação por botões, indicadores e teclado.
- Manual completo em rolagem, com índice lateral.
- Alternância entre tema escuro e claro.
- Botões para copiar comandos.
- Layout adaptável a celular e computador.
- Guia do professor em `MANUAL_DO_PROFESSOR.md`.

Não há quiz nem simulador de terminal.
