Manual Técnico: AMQP & RabbitMQ

Arquitetura, Conceitos Fundamentais e Implementação Prática em Sistemas Distribuídos

1. Introdução ao AMQP (Advanced Message Queuing Protocol)

O AMQP é um protocolo de camada de aplicação aberto e padronizado para orientação a mensagens. Ele permite que aplicações heterogêneas comuniquem-se de forma assíncrona, confiável e interoperável, garantindo que o remetente e o destinatário não precisem estar ativos ao mesmo tempo.

Conceitos Core do Modelo AMQP:

  • Publisher (Produtor): Aplicação que cria e envia a mensagem.
  • Exchange (Roteador): Recebe as mensagens do Publisher e decide para quais filas (Queues) elas devem ser enviadas com base em regras chamadas Bindings.
  • Queue (Fila): Buffer que armazena as mensagens até que sejam consumidas.
  • Consumer (Consumidor): Aplicação que se conecta à fila e processa as mensagens.

2. Tipos de Exchanges no RabbitMQ

Tipo Comportamento Caso de Uso Ideal
Direct Roteia mensagens para filas cuja chave de roteamento (Routing Key) exata coincide com a chave da mensagem. Processamento de tarefas direcionadas (ex: filas de logs específicos).
Fanout Ignora a Routing Key e envia cópias da mensagem para *todas* as filas vinculadas a ela. Sistemas de Broadcast / Publicação de Eventos (Pub/Sub).
Topic Roteia mensagens usando padrões coringa (wildcards) na Routing Key (ex: stock.us.*). Sistemas complexos de roteamento baseados em múltiplos atributos.
Headers Usa atributos do cabeçalho da mensagem em vez de routing keys para o roteamento. Roteamento flexível baseado em metadados ricos.

3. Exemplo Prático com Node.js (TypeScript)

Abaixo está um exemplo básico de conexão, envio e consumo utilizando a biblioteca amqplib:

import amqp from 'amqplib';

async function run() {
    // 1. Conexão com o RabbitMQ
    const connection = await amqp.connect('amqp://localhost');
    const channel = await connection.createChannel();

    const queue = 'task_queue';
    const msg = 'Olá, Arquitetura Orientada a Mensagens!';

    // 2. Garantir que a fila existe
    await channel.assertQueue(queue, { durable: true });

    // 3. Enviar mensagem
    channel.sendToQueue(queue, Buffer.from(msg), { persistent: true });
    console.log(" [x] Enviado: '%s'", msg);

    // 4. Fechar conexão após envio de exemplo
    setTimeout(() => {
        connection.close();
        process.exit(0);
    }, 500);
}

run().catch(console.error);

4. Garantias e Confiabilidade

Para garantir que nenhuma mensagem seja perdida em ambientes de produção, o RabbitMQ implementa:

  • Durable Queues: As filas sobrevivem a reinicializações do servidor RabbitMQ.
  • Message Persistence: As mensagens são salvas em disco.
  • Publisher Confirms: O broker confirma ao produtor que a mensagem foi persistida com sucesso.
  • Manual Acknowledgements (Acks): O consumidor só remove a mensagem da fila após processá-la com sucesso.
